# Adapter - Exemplo em Java

Este projeto é um exemplo simples de como aplicar o padrão de projeto **Adapter**.

## 📌 O que é o Adapter?

O **Adapter** é um padrão estrutural que permite que classes com interfaces diferentes trabalhem juntas. Ele atua como um "conector" entre interfaces incompatíveis.

## 🚀 Tecnologias usadas

- Java
